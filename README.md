### 📊 Análise de Performance — Google Ads (Mídia Paga)
<img align="right" width="500" src="https://github.com/KathAlmeida/GoogleADS_Portf-lio/blob/main/IMAGES/image.jpg?raw=true">

Projeto desenvolvido para centralizar, automatizar e analisar a performance de campanhas de tráfego pago no setor de climatização. 

A solução elimina a dependência de relatórios estáticos em PDF, transformando dados brutos extraídos via API em um painel estratégico no Power BI focado na otimização de investimentos e geração de leads em tempo real.

### 🔍 Principais análises e insights de negócio:
- **Diagnóstico de Sazonalidade Local:** Mapeamento do comportamento de safra (Verão vs. Outono) comprovando o impacto da urgência de mercado no volume de leads e na redução do CPC.
- **Monitoramento de Eficiência de Mídia:** Acompanhamento de metas técnicas reais de mercado (CTR > 5% e Conversão de Página > 12%).
- **Evolução de Funil (Marketing ➔ Vendas):** Planejamento estratégico para integrar dados de fechamento comercial e mensurar o ROI real sobre o investimento.

### ⚙️ Engenharia de Dados e Desafios Superados:
- **Automação de ETL:** Integração e extração automatizada de dados diretamente do Google Ads usando SyncWith.
- **Resolução de Limitações da API:** Decisão analítica para contornar a ausência de dados geográficos, demográficos e quebras na hierarquia de *Ad Groups* devido às travas de privacidade (LGPD) da plataforma.
- **Modelagem e Tratamento:** Tratamento, limpeza e desduplicação de dados brutos utilizando o Power Query.

### Análise de Dados - E-commerce Olist
<img align="right" width="500" src="https://github.com/user-attachments/assets/b6842913-2f33-42cf-921b-74dfc8b5089b">

Projeto desenvolvido com foco em análise de performance, comportamento de clientes, logística e satisfação em um e-commerce.
A análise foi construída utilizando SQL para tratamento e modelagem dos dados e Power BI para visualização e geração de insights de negócio.

### 🔍 Principais análises realizadas:
- Faturamento e sazonalidade de vendas
- Ticket médio e volume de pedidos
- Retenção e recorrência de clientes
- Performance logística e entregas no prazo
- Relação entre prazo de entrega e satisfação do cliente

### ⚙️ Principais desafios técnicos:
- Criação manual das tabelas no SQL Server
- Tratamento e padronização de dados
- Correção de valores inflados causados por tipagem incorreta
- Construção de métricas de negócio utilizando CTEs e subqueries
